# 验证码发送故障排查

## 常见问题

### 1. 网络请求失败

**症状**: 前端显示"网络请求失败，请检查网络连接"

**可能原因**:
- 后端服务未启动
- 前端无法连接到后端（地址或端口错误）
- 防火墙阻止连接

**解决方法**:

1. **检查后端服务是否启动**
```bash
cd backend
python main.py
```
应该看到类似输出：
```
INFO:     Uvicorn running on http://0.0.0.0:8000
```

2. **测试后端连接**
```bash
# 在浏览器中访问
http://localhost:8000

# 或使用测试脚本
python 测试后端连接.py
```

3. **检查前端API地址**
- 打开 `frontend1/utils/api.js`
- 确认 `BASE_URL` 为 `http://localhost:8000` 或 `http://127.0.0.1:8000`
- 在HBuilderX中，如果使用 `127.0.0.1` 无法连接，尝试使用 `localhost`

4. **检查端口占用**
```bash
# macOS/Linux
lsof -i :8000

# 如果端口被占用，可以修改后端端口
# 在 main.py 中修改: uvicorn.run(app, host="0.0.0.0", port=8001)
```

### 2. 短信发送失败

**症状**: 后端返回"短信发送失败"

**可能原因**:
- 短信平台账号余额不足
- 短信平台API地址错误
- 网络问题导致无法连接短信平台

**解决方法**:

1. **检查短信平台配置**
   - 打开 `backend/app/services/sms_service.py`
   - 确认账号、密码、API地址正确

2. **查看后端日志**
   - 启动后端时查看控制台输出
   - 查看是否有错误信息

3. **测试短信服务**
   - 可以直接调用 `send_sms()` 函数测试
   - 检查返回的错误信息

### 3. 验证码接口返回500错误

**可能原因**:
- 数据库连接失败
- 数据库表未创建
- 短信服务异常

**解决方法**:

1. **检查数据库**
```bash
# 确认MySQL服务运行
# 确认数据库 my_app 已创建
# 确认表 verification_codes 已创建
```

2. **重新创建表**
```python
# 在Python中执行
from app.database import engine, Base
from app.models import VerificationCode
Base.metadata.create_all(bind=engine)
```

### 4. HBuilderX中无法连接本地后端

**解决方法**:

1. **使用localhost代替127.0.0.1**
   - 修改 `frontend1/utils/api.js` 中的 `BASE_URL`

2. **配置代理（如果使用H5运行）**
   - 在 `manifest.json` 中配置代理
   - 或使用HBuilderX的内置代理功能

3. **检查HBuilderX运行模式**
   - 如果使用"运行到浏览器"，确保浏览器可以访问 localhost:8000
   - 如果使用"运行到手机模拟器"，可能需要使用电脑的IP地址

## 调试步骤

1. **打开浏览器开发者工具**
   - 查看Network标签
   - 查看请求是否发出
   - 查看响应状态码和内容

2. **查看后端日志**
   - 启动后端时查看控制台
   - 查看是否有错误堆栈

3. **使用测试脚本**
```bash
python backend/测试后端连接.py
```

4. **检查前端控制台**
   - 在HBuilderX中查看控制台输出
   - 查看是否有JavaScript错误

## 快速检查清单

- [ ] 后端服务已启动（运行在8000端口）
- [ ] 可以访问 http://localhost:8000
- [ ] 前端API地址配置正确
- [ ] MySQL服务运行正常
- [ ] 数据库和表已创建
- [ ] 短信平台账号配置正确
- [ ] 网络连接正常
