# 后端启动说明

## 前置条件

1. **安装Python 3.8+**
2. **安装MySQL 5.7+** 并启动MySQL服务
3. **确保MySQL可以连接**
   - 地址：127.0.0.1:3306
   - 用户名：root
   - 密码：REDACTED_SECRET

## 快速开始

### 1. 安装依赖

```bash
cd backend
pip install -r requirements.txt
```

### 2. 启动后端服务

```bash
python main.py
```

或者使用uvicorn：

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 3. 验证服务

- 访问 http://localhost:8000 查看API信息
- 访问 http://localhost:8000/docs 查看交互式API文档
- 访问 http://localhost:8000/redoc 查看ReDoc文档

## 数据库说明

- **首次启动会自动创建数据库** `my_app`
- **自动创建用户表** `users`
- 无需手动执行SQL语句

## 前端配置

前端代码已配置为连接 `http://127.0.0.1:8000`

如需修改，请编辑 `frontend1/utils/api.js` 中的 `BASE_URL`

## 常见问题

1. **数据库连接失败**
   - 检查MySQL服务是否启动
   - 检查用户名密码是否正确
   - 检查端口是否为3306

2. **端口被占用**
   - 修改 `main.py` 中的端口号
   - 或使用 `uvicorn main:app --port 8001` 指定其他端口

3. **依赖安装失败**
   - 使用国内镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`
