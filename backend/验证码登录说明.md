# 验证码登录功能说明

## 功能概述

已实现完整的手机验证码登录功能，包括：
1. 发送验证码接口
2. 验证码登录接口
3. 前端验证码登录页面

## 后端接口

### 1. 发送验证码
- **接口**: `POST /api/auth/send-code`
- **请求体**:
```json
{
  "phone": "19994729367"
}
```
- **响应**:
```json
{
  "message": "验证码已发送，请查收短信",
  "success": true
}
```

### 2. 验证码登录
- **接口**: `POST /api/auth/code-login`
- **请求体**:
```json
{
  "phone": "19994729367",
  "code": "123456"
}
```
- **响应**:
```json
{
  "token": "jwt_token_here",
  "user": {
    "id": 1,
    "nickname": "用户8000",
    "phone": "19994729367",
    "email": null,
    "avatar": null,
    "created_at": "2024-01-01T00:00:00"
  }
}
```

## 功能特性

1. **验证码有效期**: 5分钟
2. **验证码长度**: 6位数字
3. **自动创建用户**: 如果用户不存在，验证码登录时会自动创建用户
4. **验证码使用**: 每个验证码只能使用一次
5. **错误处理**: 验证码错误或过期时直接返回错误，不限制错误次数

## 数据库表

### verification_codes 表
- `id`: 主键
- `phone`: 手机号（索引）
- `code`: 验证码
- `is_used`: 是否已使用
- `created_at`: 创建时间
- `expires_at`: 过期时间

## 前端功能

1. **登录方式切换**: 支持密码登录和验证码登录两种方式
2. **发送验证码**: 点击"发送验证码"按钮，60秒倒计时
3. **验证码输入**: 6位数字验证码输入框
4. **自动登录**: 验证码校验成功后自动登录

## 使用流程

1. 用户选择"验证码登录"
2. 输入手机号
3. 点击"发送验证码"
4. 收到短信验证码
5. 输入验证码
6. 点击"登录"
7. 系统校验验证码，成功后返回token并自动登录

## 注意事项

1. 确保MySQL服务已启动
2. 确保短信平台账号有足够余额
3. 验证码5分钟后自动过期
4. 每个验证码只能使用一次
5. 如果用户不存在，会自动创建新用户（昵称为"用户+手机号后4位"）
