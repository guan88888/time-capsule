# 后端快速启动指南

## 方法一：使用启动脚本（推荐）

### macOS/Linux
```bash
cd backend
./start.sh
```

### Windows
```bash
cd backend
start.bat
```

## 方法二：手动启动

### 1. 进入后端目录
```bash
cd backend
```

### 2. 安装依赖（首次运行）
```bash
pip install -r requirements.txt
```

如果使用Python3：
```bash
pip3 install -r requirements.txt
```

如果安装慢，可以使用国内镜像：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3. 确保MySQL服务运行
- macOS: 检查系统偏好设置中的MySQL
- Windows: 检查服务管理器中的MySQL服务
- Linux: `sudo systemctl status mysql`

### 4. 启动后端服务
```bash
python main.py
```

或使用Python3：
```bash
python3 main.py
```

### 5. 验证服务运行
看到以下输出说明启动成功：
```
INFO:     Started server process
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
```

## 访问服务

启动成功后，可以通过以下地址访问：

- **API根路径**: http://localhost:8000
- **交互式API文档**: http://localhost:8000/docs
- **ReDoc文档**: http://localhost:8000/redoc

## 常见问题

### 1. 提示"ModuleNotFoundError"
**解决**: 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 提示"无法连接MySQL"
**解决**: 
- 确认MySQL服务已启动
- 检查用户名密码是否正确（默认：root/REDACTED_SECRET）
- 检查端口是否为3306

### 3. 端口8000被占用
**解决**: 修改 `main.py` 中的端口号
```python
uvicorn.run(app, host="0.0.0.0", port=8001)  # 改为8001或其他端口
```

### 4. 数据库不存在
**解决**: 首次运行会自动创建数据库 `my_app`，如果失败请手动创建：
```sql
CREATE DATABASE my_app CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

## 停止服务

在运行服务的终端中按 `Ctrl+C` 停止服务。

## 开发模式（自动重载）

如果需要代码修改后自动重载，可以使用：
```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```
