# 快速开始指南

## 前置准备

1. 安装 HBuilderX 开发工具
2. 确保 HBuilderX 已安装 uni-app 插件

## 运行步骤

1. **打开项目**
   - 在 HBuilderX 中选择"文件" -> "打开目录"
   - 选择 `frontend1` 文件夹

2. **配置 TabBar 图标**（重要）
   - 在 `static/tabbar/` 目录下添加以下图标文件：
     - `home.png` / `home-active.png` (81x81px)
     - `capsule.png` / `capsule-active.png` (81x81px)
     - `achievement.png` / `achievement-active.png` (81x81px)
     - `profile.png` / `profile-active.png` (81x81px)
   - 如果暂时没有图标，可以临时注释掉 `pages.json` 中的 `tabBar` 配置

3. **运行项目**
   - 点击 HBuilderX 工具栏的"运行"按钮
   - 选择运行到浏览器/App/小程序

## 功能测试

### 1. 登录/注册
- 首次打开会跳转到登录页
- 可以注册新账号（模拟数据，无需真实后端）

### 2. 创建胶囊
- 点击首页右下角的 "+" 按钮
- 选择胶囊类型
- 填写内容并设置解锁时间
- 保存后返回首页查看

### 3. 解锁胶囊
- 在胶囊列表中选择待解锁的胶囊
- 等待倒计时结束或手动解锁（如果已到时间）
- 查看胶囊内容并进行回顾

### 4. 情绪日历
- 在个人中心 -> 情绪日历
- 查看情绪记录和统计

### 5. 成就系统
- 完成特定任务会自动解锁成就
- 在成就中心查看已解锁和未解锁的成就

## 注意事项

1. **数据存储**: 所有数据存储在本地，清除应用数据会丢失所有胶囊
2. **加密方式**: 当前使用Base64编码，仅用于演示，生产环境需使用更安全的加密
3. **API接口**: 当前使用模拟数据，实际部署需要连接后端API
4. **图标资源**: TabBar图标需要自行添加，否则底部导航栏可能无法正常显示

## 常见问题

**Q: TabBar不显示？**
A: 需要添加图标文件，或临时注释掉 `pages.json` 中的 `tabBar` 配置

**Q: 登录后无法跳转？**
A: 检查 `App.vue` 中的登录检查逻辑，确保 token 正确设置

**Q: 胶囊无法解锁？**
A: 检查解锁时间是否已到，或查看 `unlock.vue` 中的解锁逻辑
